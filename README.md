**Tools for working with AI agents.** *Senior Rounds*: a comprehension-first
way to go over what your agents changed — cards, not diffs. The agent says what it wasn't sure
about and what you didn't ask for; you predict before you look. Contract-first: any agent that
can write a file can feed it. Coming soon.

**ML from scratch.** PyTorch, one component at a time, each isolated and self-checking:
- [modern-nanoGPT](https://github.com/LeonelSalvo/modern-nanoGPT) — the GPT-2 skeleton plus RMSNorm, RoPE, SwiGLU, GQA
- [frontier-llm-techniques-2026-Q1](https://github.com/LeonelSalvo/frontier-llm-techniques-2026-Q1) — Muon, Multi-Token Prediction, a base BPE tokenizer
- [nano-moe-mla](https://github.com/LeonelSalvo/nano-moe-mla) — DeepSeek-style MoE + MLA, with a router-specialization probe

Next down the stack: CUDA and Triton kernels.

**By day.** TypeScript and Python: LangGraph agents, multi-tenant backends, Next.js frontends.
